# Security Policy

## Supported Versions

We usually support only latest version with security fixes, at the time of the edit of this page we have version 0.5.x so that one will be checked and updated to remove vulnerabilities.

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| 0.4.x   | :x:                |


## Reporting a Vulnerability

For this repo just report vulnerabilities with the standard issues tracker.
